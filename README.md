# FPGA ALU in Verilog

## Overview
This project implements a 6-instruction Arithmetic Logic Unit (ALU) in Verilog and was developed using Vivado for FPGA-based digital design practice.

## Features
- Arithmetic and logic operations
- Register transfer logic
- Multiplexer integration
- Flip-flop based components
- Functional verification using simulation waveforms

## Technologies Used
- Verilog
- Vivado
- FPGA Design
- Digital Logic

## Project Structure
- `src/` contains Verilog source files
- `testbench/` contains simulation testbenches
- `images/` contains waveform screenshots

## Results
The ALU was successfully simulated and validated through waveform analysis and functional verification.
